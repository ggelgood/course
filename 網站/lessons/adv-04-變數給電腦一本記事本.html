變數：給電腦一本記事本

想做一個「按一下加一分」的東西，但翻遍積木區，沒有一塊積木會記東西。今天要自己做一個能記數字的盒子。

今天要做出什麼

一個叫分數的盒子，可以裝一個數字，而且舞台上看得到它。

今天的新積木

建立一個變數
將 分數 設為 0

今天只學「是什麼」，還不學怎麼用它做東西——那是下禮拜的事。

1分數要放在哪裡？

想像你要做一個「按一下小貓，分數加一分」的東西。動作、外觀、事件……翻遍所有分類，找不到一塊「存數字」的積木。

因為 Scratch 本來就沒有一個叫「分數」的東西。想要有，得自己造一個出來——這就是變數要做的事。

💡 變數是什麼

  • 想成一個有名字的盒子，可以裝一個數字（或一小段文字）。
  • 盒子裡的數字可以換——這就是「變」數的意思，跟數學課的固定數字不一樣。
  • 今天你會自己造一個盒子出來，取名叫「分數」。

2建立一個變數

點左邊積木區的「變數」分類，會看到一顆「建立一個變數」的按鈕（不是積木，是按鈕）。點下去，跳出一個框要你取名字。

建立一個變數

取名字是今天最重要的一步。 有人會偷懶打「變數1」——三個禮拜後回來看自己的程式，完全看不懂「變數1」是在記什麼。

要做一個記錄玩家生命值的變數，下面哪個名字最好？

想像三個禮拜後你自己回來看這個程式。

偷看一下：變數用打字的怎麼寫？好奇再點 
score = 0          # 建立一個叫 score 的變數，裡面放 0

在打字的程式語言裡，不用先「建立」再「設為」，寫一行就兩件事一起做完了。 score = 0 這一行，等號左邊是變數的名字，右邊是要放進去的數字。

這是整個進階課最值得記住的一個對照——不管是 Scratch 的橘色積木，還是 Python 打的這一行字，做的都是同一件事：造一個盒子，放進一個數字。

⚠️ 建好變數，但監看框不見了？

  • 變數積木最左邊有一個小方格，勾起來監看框才會出現在舞台上。
  • 不小心點到取消勾選，變數不會消失，只是不顯示，重新勾起來就回來了。
  • 拖動監看框可以換位置，不會擋到角色就好。

4換你在 Scratch 裡做

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 5
  1. 點「變數」分類 → 建立一個變數，取名叫分數
  2. 確認舞台左上角出現分數的監看框，數字是 0
  3. 拼出：當綠旗被點擊 → 將分數設為 0
  4. 拼出：當角色被點擊 → 將分數設為 100，按按看角色，數字真的變了
  5. 再建一個新變數，取名叫生命值，設為 3
