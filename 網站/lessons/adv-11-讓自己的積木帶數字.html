讓自己的積木帶數字

要閃三下、閃五下、閃十下，難道要做三塊積木？ 今天讓一塊積木自己記得「這次要做幾次」。

今天要解決的問題

同一塊「閃爍」積木，呼叫的時候自己填要閃幾下。

今天的新東西

積木的「數字輸入」欄位——幫積木留一個洞，讓呼叫的人自己填。

1閃三下、閃五下……難道要做三塊積木？

上禮拜的「閃爍」積木，肚子裡固定寫死「重複 3 次」。如果某個角色想閃五下，難道要另外再做一塊「閃爍五下」？再一塊「閃爍十下」？

今天的做法：讓「閃爍」自己留一個洞，呼叫的時候把數字填進去。這個洞，叫做參數。

2幫積木加一個數字輸入

在「我的積木」分類裡，右鍵點「閃爍」積木（或點旁邊的編輯按鈕），選「編輯」，會跳出積木編輯視窗。點「＋ 加入輸入項」→ 數字，取名叫「幾下」。

確定之後，定義帽子變成這樣：

定義 閃爍 幾下

「幾下」變成一個橢圓形的洞，接在帽子上。這個洞就是「參數」——每次呼叫的時候，可以填不一樣的數字進去。

3把參數拖進「重複」的洞裡

光加參數還不夠，要把它從定義帽子上拖下來，塞進「重複 3 次」的數字格，取代原本寫死的 3：

成功之後，定義會變成：

定義 閃爍 幾下
重複 幾下 次
隱藏
等待 0.2 秒
顯示
等待 0.2 秒

下面比較兩種做法。改改看呼叫時填的數字，看兩邊的差別：

😖 版本 A：手打數字
定義 閃爍 幾下
重複 3 次

😎 版本 B：拖參數進洞裡
定義 閃爍 幾下
重複 幾下 次

版本 A 看起來也能「呼叫並執行」，按下去角色真的會閃。為什麼版本 A 是錯的？

試試看，在上面把呼叫的數字從 5 改成 10，兩邊有什麼不一樣。

⚠️ 這是本課最容易踩的坑

看起來會動，不代表是對的。檢查的方法很簡單：呼叫的時候換一個數字，結果有沒有跟著變。沒有變，就是漏掉「拖參數進洞裡」這一步。

偷看一下：帶參數的積木用打字的怎麼寫？好奇再點 
def 閃爍(次數):          # 定義 閃爍，參數叫「次數」
    for i in range(次數):
        hideturtle(); sleep(0.2)
        showturtle(); sleep(0.2)

閃爍(5)                 # 呼叫，填 5 進去

括號裡的次數，跟 Scratch 橢圓形洞裡的幾下是同一件事——都是「呼叫的人可以自己填」的數字。名字在兩邊完全對應：定義時取的參數名字，肚子裡就用那個名字。

4換你在 Scratch 裡做

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 4
  1. 編輯「閃爍」積木，加入數字輸入，取名幾下
  2. 把定義裡的「重複 3 次」拖成「重複 幾下 次」（不是手打）
  3. 回到主程式，呼叫的地方會多一個空格，填不同的數字試試看（5、10、2）
  4. 確認換數字，閃爍的次數真的跟著變

🙋 怎麼確認自己真的懂參數

問自己一個問題：「這個洞要取什麼名字？」 答得出「幾下」「幾邊」這種看得懂用途的名字，就是真的懂了；答不出來，或只會說「數字」，代表還在照抄。

5挑戰：一塊積木，兩個參數

參數不只能有一個。試著把第 3 課畫圖形的程式包成一塊積木，取名「正N邊形」，帶兩個數字輸入：邊數和邊長。

定義 正N邊形 邊數 邊長

肚子裡用「重複 邊數 次：移動 邊長 點、右轉 360÷邊數 度」——這樣呼叫正N邊形(6, 80)就能畫出邊長 80 的正六邊形。
