自製積木：做一塊自己的積木

上禮拜改三次，改到手軟。今天教你把一段程式包成一塊積木、取一個名字——改一次，全部都跟著變。

今天要解決的問題

把上禮拜的「閃爍三下」包成一塊叫「閃爍」的積木，三個角色一起用。

今天的新積木

定義 閃爍
閃爍

1上禮拜的痛，今天解決

上禮拜「閃爍三下」被老師臨時改了兩次需求，每次都要三個角色分別改。今天要學的積木，就是為了解決這件事而存在的。

💡 自製積木在做什麼

  • 把一段程式包起來，取一個名字，變成一塊新的積木。
  • 之後想用這段程式，不用重新拼一次，呼叫這個名字就好。
  • 最厲害的地方：改一次定義，所有呼叫它的地方全部一起變。

2建立一個積木，取名叫「閃爍」

點左邊積木區最下面的「我的積木」分類，會看到一顆「建立一個積木」按鈕。點下去，跳出命名框，打「閃爍」。

確定之後，程式區會出現一塊新的帽子積木：

定義 閃爍

把上禮拜「重複 3 次」那一段，搬到這塊帽子底下：

定義 閃爍
重複 3 次
隱藏
等待 0.2 秒
顯示
等待 0.2 秒

⚠️ 定義區只放「做什麼」，不放「什麼時候做」

  • 很多人會想把「當綠旗被點擊」接到「定義 閃爍」底下——不要，這是本課最常見的錯。
  • 「定義」底下只放要做的事（重複、隱藏、顯示⋯），「什麼時候要做」是呼叫的人決定的，不是定義的人決定的。

3三個角色都改成「呼叫」

定義做好之後，「我的積木」分類裡會多出一塊新積木：

閃爍

把三個角色原本的「重複 3 次…」整段刪掉，換成呼叫它：

⚑ 當綠旗被點擊
閃爍

三個角色的程式現在只剩兩塊積木，而且都在呼叫同一個「閃爍」。

4見證奇蹟：改一次，三個都變

打開任何一個角色的「定義 閃爍」，把「重複 3 次」改成「重複 6 次」。然後分別點回三個角色，按綠旗。

上禮拜複製程式，改一個角色不會影響其他角色。今天呼叫同一塊「閃爍」，改一次定義，三個角色卻會一起變。差別在哪？

想想「複製一份」跟「呼叫同一塊」有什麼不一樣。

偷看一下：自製積木用打字的怎麼寫？好奇再點 
def 閃爍():              # 定義 閃爍
    for i in range(3):
        hideturtle()
        sleep(0.2)
        showturtle()
        sleep(0.2)

閃爍()                   # 呼叫 閃爍

def 是「定義」的意思。冒號後面縮排的部分，就是這塊自製積木「肚子裡」的內容——跟「重複」的縮排是同一套規則。

最後一行 閃爍()，後面那對括號代表「呼叫」——這是整個進階課最重要的一塊橋：不管是 Scratch 拖一塊粉紅色積木，還是 Python 打函式名字加括號，做的是同一件事。

5命名練習：再包兩塊

把下面這兩段常見的動作，也各自包成一塊自製積木。名字要讓人一看就知道它會做什麼，不要取「積木1」「積木2」。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 2
  1. 把「改變 y 30、等 0.2 秒、改變 y -30」包成一塊積木，取名跳起來
  2. 把「尺寸改變 20、等 0.2 秒、尺寸改變 -20」包成一塊積木，取名變大再變小

⚠️ 這一課的三個常見狀況

  • 把「當綠旗被點擊」接到定義帽子底下 —— 定義區不放事件積木，事件放在呼叫的地方就好。
  • 建好定義但沒有呼叫 —— 按綠旗什麼都沒發生，檢查角色的主程式有沒有真的接上「閃爍」。
  • 積木名稱取「積木1」 —— 跟第 4 課的變數命名同一個問題，回去重新取一個看得懂的名字。
