作品：小小躲避遊戲

學到這裡，你已經有做出一個真正的遊戲需要的全部東西了。

今天要做出什麼

用方向鍵控制角色，躲開飛來飛去的球，被碰到就結束。

今天怎麼上

不教新積木。重點是「調難度」——太難沒人玩得下去，太簡單很無聊。

1今天不教新積木

你手上已經有全部零件了。今天的工作是把它們組成一個好玩的遊戲。

🙋 第 14 課沒跟上的，今天可以補

  • 如果「重複無限次包住如果」還不太會，今天先回第 14 課把那個練習做完。
  • 今天沒有進度壓力。做出「碰到就結束」就算完成。
  • 做完最低要求之後，下面還有很多可以加的。

🎮 難度是設計出來的，不是隨便設的

  • 球速：太慢無聊，太快沒人躲得掉。4～6 通常最好玩。
  • 球的數量：多一顆球，難度不是加倍，是好幾倍。先做一顆，好玩了再加。
  • 主角的移動點數：主角要比球靈活一點，玩起來才有得閃。
  • 調到「差一點就被碰到」最好玩——太簡單和太難都會讓人不想玩。

4動手做

分成三關。第一關一定要做到，後面兩關做得到多少算多少。

🥉 第一關 · 一定要做到 做完一步就打勾 👇 0 / 5
  1. 放兩個角色：主角（你控制）和球（自己飛）
  2. 幫主角寫四串方向鍵控制
  3. 幫球寫：綠旗 → 面朝 45 度 → 重複無限次（移動 ＋ 碰到邊緣就反彈）
  4. 幫主角再開一串：綠旗 → 重複無限次 → 如果碰到球，就說「被碰到了！」
  5. 按綠旗玩玩看，確認球會飛、你能躲、碰到會有反應
🥈 第二關 · 做完了再加 讓它像個真的遊戲 👇 0 / 4
  1. 碰到的時候加上 停止 [全部]，遊戲真的會結束
  2. 在綠旗那串加 定位到 x:0 y:0，每次重玩都從中間開始
  3. 調球速和主角的移動點數，找出最好玩的組合
  4. 加背景和音效（被碰到的時候叫一聲）
🥇 第三關 · 還有時間就挑戰 挑你想做的，不用全做 👇 0 / 4
  1. 加第二顆球，用不同的角度和速度（複製整個角色最快）
  2. 加一顆要吃的星星：碰到星星就隱藏，做出「邊躲邊收集」
  3. 用廣播做遊戲結束：碰到就廣播「遊戲結束」，所有球一起停下來
  4. 開場讓主角說明玩法：「用方向鍵閃開球！」

⚠️ 卡住了？先看這裡

  • 球不會動 —— 移動和反彈有沒有放在重複無限次的肚子裡？
  • 球只會左右飛 —— 開場的「面朝」是不是 90 度？改成 45 度之類的斜角。
  • 碰到完全沒反應 —— 「如果」有沒有包在重複無限次裡面？沒有的話只檢查一次。
  • 碰到之後停不下來 —— 加一塊 停止 [全部] 在如果的肚子裡。
  • 重玩的時候角色位置很怪 —— 綠旗那串加 定位到 x:0 y:0。
  • 球太快躲不掉 —— 把球的移動點數改小，或把主角的改大。
  • 六個都試過還是不行，再舉手找老師。

5做完了，記得存檔

💾 存檔 三步，一定要做完 👇 0 / 3
  1. 點「檔案 → 儲存到你的電腦」
  2. 檔名取 座號_姓名_躲避遊戲
  3. 存在老師說的那個資料夾裡

6互相試玩，然後調難度

遊戲要別人玩過才知道好不好玩。你自己做的，你早就知道球會往哪飛了。

① 玩得下去嗎？ 撐得過 10 秒嗎？還是一開始就被撞到？
② 知道怎麼玩嗎？ 沒人講解的話，你知道要按什麼、目標是什麼嗎？
③ 還想再玩一次嗎？ 這是最重要的問題。如果會想再玩，難度就調對了。

🔧 聽完意見，回去調一次

  • 同學說太難 → 球速調慢，或主角移動點數調大。
  • 同學說太簡單 → 球速調快，或加第二顆球。
  • 同學說看不懂怎麼玩 → 開場加一句說明。
  • 根據別人的意見改東西，是真正的遊戲設計師每天在做的事。
