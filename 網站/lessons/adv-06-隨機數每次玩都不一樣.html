隨機數：每次玩都不一樣

做出來的東西玩第二次就膩了，因為每次都一模一樣。今天讓電腦自己「擲骰子」。

今天要做出什麼

角色每次出現的位置、大小、顏色都不一樣——靠一塊會擲骰子的積木。

今天的新積木

隨機取數 1 到 10
— × ÷ +

1玩第二次就膩了

如果你做的東西每次出現的位置都一樣，第一次玩很新鮮，第二次就知道答案在哪，第三次就不想玩了。

今天這一塊積木在運算分類裡：

隨機取數 1 到 10

它每次執行都會吐出一個範圍內的亂數，就像擲骰子——你不知道下一次是多少，電腦也是。

2隨機取數，塞進定位到

「隨機取數」自己不會做任何事，它要塞進另一塊積木的洞裡才有用。塞進上禮拜學的「定位到 x: y:」，角色就會亂跳：

定位到 x: 隨機取數 -240 到 240 y: 隨機取數 -180 到 180

−240 到 240、−180 到 180——這正是第 1 課的舞台範圍。 上禮拜你花一整節課搞懂的邊界數字，今天用上了。

下面這台按「跳到隨機位置」，每按一次角色就跳到一個新地方，落點會留一個小點：

🐱

連按十次左右，看看點是不是散落在整個舞台——這就是隨機的樣子。

偷看一下：隨機取數用打字的怎麼寫？好奇再點 
import random                  # 要先「借」隨機這個功能

n = random.randint(1, 10)     # 隨機取數 1 到 10

Python 要多寫一行 import random，意思是「跟系統借『隨機』這個功能來用」——內建的功能不用借，但比較特別的（隨機、畫筆）要先借才能用。

3隨機取數不只能塞進定位

任何積木裡只要有白色的數字格子，都可以塞隨機取數進去：

尺寸設為 70 %
塞進去 → 角色每次出現大小都不一樣
改變顏色特效 25
塞進去 → 角色顏色隨機變化
等待 1 秒
塞進去 → 每次停頓的時間都不同，感覺比較不呆板

如果把「隨機取數」的兩個格子填反，寫成「隨機取數 10 到 1」，會發生什麼事？

想想看範圍的「頭」和「尾」代表什麼。

4換你在 Scratch 裡做

🥉 第一關 · 一定要做到 做完一步就打勾 👇 0 / 3
  1. 拼出：當綠旗被點擊 → 重複無限次 → 等待 1 秒 → 定位到 (隨機 -240~240, 隨機 -180~180)
  2. 按綠旗，看角色是不是每秒跳到新地方
  3. 試著把兩個數字範圍故意填反，看看會發生什麼
🥈 第二關 · 做完了再加 把隨機塞進更多地方 👇 0 / 2
  1. 加一塊尺寸設為 隨機取數 50 到 150，角色大小也跟著變
  2. 加一塊改變顏色特效 隨機取數 0 到 200
🥇 第三關 · 還有時間就挑戰 挑你想做的，不用全做 👇 0 / 3
  1. 猜數字：建一個變數存 隨機取數 1 到 10，做一個「說出」把答案講出來，跟旁邊同學互相猜
  2. 星星特效：多放幾個角色，每個都隨機換位置，湊出一片會眨眼的星空
  3. 加權計分：分數改變 隨機取數 1 到 3，讓每次加的分數也不一樣

⚠️ 卡住了？先看這裡

  • 角色不動 —— 檢查「隨機取數」有沒有真的塞進「定位到」的格子裡，還是掉在旁邊沒接上。
  • 只出現在同一個地方 —— 檢查範圍是不是填反了（例如 10 到 1）。
  • 角色一直閃 —— 「等待」忘了放，跳得太快看起來像閃爍。
