作品：接東西計分遊戲

今天不教新積木。把變數、隨機、碰到判斷全部組起來，做出這學期第一個真的能玩的東西。

今天要做出什麼

蘋果從天上不斷掉下來，用方向鍵移動的碗去接，接到分數加一分。

今天怎麼上

時間最緊的一課，直接打開半成品範例檔，不用從零開始搭。

1單元二的終點

前四節課：變數、設為與改變、隨機、如果否則。今天全部用上，做一個會計分、會結束、玩起來有意思的東西——不是「會動的作品」，是「可以玩的遊戲」。

⚠️ 一定要打開範例檔，不要從零搭

  • 今天時間最緊。範例檔裡兩個角色、背景都已經放好，程式是空的，直接開始拼積木就好。
  • 從零搭角色、背景會用掉太多時間，光準備就沒時間玩到「真的在玩遊戲」的感覺。

2你會用到這些積木

全部都是前四節課學過的。忘記哪一塊做什麼，看這裡就好：

將 分數 設為 0
綠旗開頭一定要有，不然重玩會接著上次的分數（第 5 課的坑）
定位到 x: 隨機 y: 180
蘋果每次從上緣隨機的 x 位置重新掉下來
改變 y -5
y 愈變愈小，蘋果往下掉
如果 碰到 蘋果 ▾？ 那麼
碗跟蘋果重疊時，這裡面的事才會發生
將 分數 改變 1
接到一次加一分——是「改變」不是「設為」
重複無限次
改變 y -5
蘋果要一直掉，所以包在無限重複裡

3先做蘋果：掉下來、掉到底重來

點選「蘋果」角色，拼出這串：

⚑ 當綠旗被點擊
定位到 x: 隨機取數 -200 到 200 y: 170
重複無限次
改變 y -5
如果 y 座標 < -170 ？ 那麼
定位到 x: 隨機取數 -200 到 200 y: 170

念出來就是：蘋果不斷往下掉，掉到底就跳回頂端，換一個新的隨機位置重新掉。

如果把「如果 y 座標 < -170」判斷放在無限重複外面（跟重複同一層，不是包在裡面），會發生什麼事？

想想「如果」只檢查一次，還是每次都檢查。

4再做碗：方向鍵移動、接到加分

點選「碗」角色：

⚑ 當綠旗被點擊
將 分數 設為 0
定位到 x: 0 y: -150
重複無限次
如果 按下 向右 ▾ 鍵？ 那麼
改變 x 10
如果 按下 向左 ▾ 鍵？ 那麼
改變 x -10
如果 碰到 蘋果 ▾？ 那麼
將 分數 改變 1

💡 為什麼移動的判斷也要放進無限重複

  • 「按下方向鍵」跟「碰到蘋果」都需要每一格畫面都重新檢查一次——放進無限重複，才能一直盯著。
  • 放外面的話，只會在綠旗那一瞬間檢查一次，之後按鍵盤完全沒反應。

5換你在 Scratch 裡做

分成三關。第一關一定要做到，後面兩關做得到多少算多少。

🥉 第一關 · 一定要做到 做完一步就打勾 👇 0 / 4
  1. 打開範例檔，選「蘋果」角色，拼出第 3 節的掉落程式
  2. 選「碗」角色，拼出方向鍵移動的部分
  3. 加上碰到蘋果就加分
  4. 按綠旗，玩一次，確認分數會累加
🥈 第二關 · 做完了再加 加一點規則 👇 0 / 3
  1. 建一個生命值變數，綠旗設為 3；蘋果碰到地板沒接到就扣一點（想想看「碰到地板」跟「y 座標 < -170」是不是同一件事）
  2. 加如果 生命值 = 0 → 停止全部（第 7 課學的）
  3. 用時間變數做限時 30 秒（第 5 課的倒數計時）
🥇 第三關 · 還有時間就挑戰 挑你想做的，不用全做 👇 0 / 3
  1. 分數愈高，蘋果掉得愈快（改變 y 的數字跟著分數變大）
  2. 加第二種掉落物（例如石頭），碰到扣分而不是加分
  3. 換一個自己喜歡的角色和背景

⚠️ 卡住了？先看這裡

  • 分數一直是 0，接到也沒反應 —— 檢查「碰到蘋果」有沒有放進無限重複裡面，還是只在最外面檢查一次。
  • 重玩一次分數沒歸零 —— 綠旗開頭忘了「分數設為 0」，第 5 課的坑又出現了。
  • 蘋果掉出畫面就不見了 —— 檢查「如果 y < -170」是不是放在無限重複裡面，不是外面。
  • 方向鍵按了角色不動 —— 檢查「如果按下…鍵」有沒有放進無限重複，只放外面只會檢查一次。
