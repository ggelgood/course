畫筆：讓角色邊走邊畫

上一課「定位到」是瞬間跳過去的，中間發生什麼看不見。今天要讓角色走過就留下線。

今天要做出什麼

一枝綁在角色身上的筆。角色走到哪，線就畫到哪——還可以換顏色、換粗細。

今天的四塊積木

下筆
停筆
全部擦掉
筆的粗細設為 1

四塊都很好懂，難的地方只有一個：它們一開始找不到。

0先把上一課沒做完的做完

上一課的座標，如果你還有兩個練習沒做完，現在花四分鐘回去把它做掉。今天整節課都會用到座標。

↩️ 回上一課

  • 四個區域，正負的組合——看題目點區域，四題
  • 反過來：看位置，說出號碼——四選一，四題

已經做完的人，直接往下。

1看不見的那一段

上一課你叫角色從中間跳到 (200, 150)。它瞬間就到了。

問題是——它「經過」了哪裡？你看不到。

其實它沒有經過任何地方，就是直接出現在那裡。但如果你想知道「從這裡到那裡」是一條什麼樣的路，光看角色是看不出來的。

今天要做的事很簡單：在角色屁股後面綁一枝筆。它走到哪，筆就畫到哪。

💡 這叫做「把看不見的東西變成看得見的」

  • 座標本身是兩個數字，很抽象。
  • 加上畫筆之後，那兩個數字變成螢幕上一條真的線。
  • 所以今天不只是學畫圖——今天是在幫上一課的座標「顯影」。

2先把畫筆裝上

畫筆積木一開始不在積木區裡。 你翻遍動作、外觀、事件都找不到，這很正常——它要自己裝。

看畫面的左下角，有一顆藍色的按鈕，長得像一塊積木加一個加號。點它，會跳出一整面的「擴充功能」。找到畫筆，點下去。

回到主畫面，積木區最下面就多了一區綠色的畫筆積木。

⚠️ 存檔之後再打開，畫筆還在嗎？

  • 在。 擴充功能會跟著作品一起存起來，下次打開這個檔案，綠色積木還在原地。
  • 但如果你開一個新作品，就要重裝一次——擴充功能是跟著作品走，不是跟著電腦走。

3下筆：走過就留下線

畫筆那一區最重要的就是這兩塊，它們是一組的：

下筆
停筆

想成「把筆壓到紙上」和「把筆提起來」。壓下去之後，角色走到哪就畫到哪；提起來之後，角色照樣會走，但不留痕跡。

下面這台可以直接玩。 先按「下筆」，再按幾次「移動」和「右轉」看看：

🐱

也可以直接用滑鼠把小貓拖著走——筆是壓下去的話，拖到哪就畫到哪。

按了「下筆」之後，如果你用滑鼠把角色拖到別的地方，會發生什麼事？

先猜，再回到上面那台試試看。

4停筆，還有全部擦掉

剛剛那個「拖到哪畫到哪」的狀況，解法就是停筆。

還有一塊你一定會用到：

全部擦掉

它把畫面上所有的線一次清光（角色不會動，只有線消失）。

⚠️ 養成一個習慣：綠旗的第一塊就是「全部擦掉」

  • 不然你每按一次綠旗，新的線會疊在舊的線上面，畫個三四次畫面就全花了。
  • 這個習慣第 3 課和第 12 課都會用到，現在養成最划算。
⚑ 當綠旗被點擊
全部擦掉
下筆

換你排排看。這一題比上面那個開頭多兩塊——畫完之後要收筆：

題目：按綠旗之後，畫一條線，然後回到舞台正中間，而且路上不可以留下痕跡。

停筆
移動 100 點
⚑ 當綠旗被點擊
定位到 x: 0 y: 0
下筆
全部擦掉

5換顏色、換粗細

剩下兩塊是拿來調整筆長什麼樣子的：

筆的顏色設為 ■
筆的粗細設為 1

兩塊都要放在畫之前——它們只影響「接下來要畫的線」，已經畫好的線不會跟著變。

這台加了顏色和粗細。試試看畫到一半換顏色，看看前面畫的會不會跟著變：

🐱
筆的顏色
筆的粗細 3

橘色那顆按鈕會用上一課的四個角落座標跑一圈。上禮拜那四組數字，現在變成看得見的一個方框了。

💡 「跑一次：走四個角落」在做什麼

  • 它做的事就是上一課的四組座標：(−200, 150) → (200, 150) → (200, −150) → (−200, −150) → 回到起點。
  • 中間會先停筆移到第一個角落，到了才下筆——不然從中間跑到角落的那一段也會被畫出來。
  • 這就是今天最重要的一句話：座標不再是兩個數字，是螢幕上一條看得見的路。
偷看一下：畫筆這幾塊用打字的怎麼寫？好奇再點 
from turtle import *      # 準備工作

clear()                   # 全部擦掉
pencolor("red")         # 筆的顏色設為 紅色
pensize(3)               # 筆的粗細設為 3
pendown()                 # 下筆
forward(100)             # 移動 100 點
penup()                   # 停筆

pen 是「筆」，down 是「下」，up 是「上」——pendown 就是「下筆」，penup 就是「停筆」。連名字都對得上。

這一課是整個 Scratch 裡跟 Python 最像的一段。Python 的這個功能叫 turtle（烏龜），因為以前真的有一隻會在紙上爬、屁股綁著筆的小機器烏龜。

6咦，怎麼什麼都沒畫出來？

這是這一課最常收到的求救。有個同學寫了這串，按下綠旗，角色確實走了，但畫面上一條線都沒有：

⚑ 當綠旗被點擊
全部擦掉
移動 100 點
右轉 90 度
移動 100 點

問題出在哪？

一塊一塊讀下來，想想少了什麼。

⚠️ 這一課的三個常見狀況

  • 什麼都沒畫出來 → 忘了「下筆」
  • 畫面愈來愈亂，一堆舊的線 → 綠旗底下忘了「全部擦掉」
  • 多了一條莫名其妙的線 → 移動之前忘了「停筆」（或是筆壓著的時候用滑鼠拖了角色）

7換你在電腦上做

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 6
  1. 點畫面左下角那顆按鈕，加入畫筆擴充功能
  2. 拼出這個開頭：當綠旗被點擊 → 全部擦掉 → 下筆
  3. 後面接移動 100 點，按綠旗，看到線了嗎
  4. 再接右轉 90 度 → 移動 100 點，畫出一個直角
  5. 在「下筆」前面加上筆的顏色設為和筆的粗細設為 5，再按一次綠旗
  6. 最後在程式的最下面接停筆 → 定位到 x: 0 y: 0，角色會回中間但不留線
🎲 試試看 不用照順序，挑喜歡的做 👇 0 / 5
用滑鼠簽自己的名字先按一下「下筆」積木，然後直接拖角色寫字。寫完記得按「停筆」。
粗細調到 20變成一枝麥克筆。再調回 1，變成原子筆。
畫到一半換顏色已經畫好的線會不會跟著變？自己看一次答案最準。
把上一課的四個角落連起來停筆 → 定位到第一個角 → 下筆 → 再定位到其他三個角。會畫出一個方框。
故意不要「全部擦掉」連按五次綠旗，看畫面變成什麼樣子。看過一次就會記得為什麼要擦。

★做完了？來挑戰

挑戰一

畫一個「正方形」：四條一樣長的邊，四個直角。

卡住了？看提示先自己想 3 分鐘

需要「移動 → 右轉」重複四次。你可以先笨笨地複製貼上四組，先做出來再說。

右轉要轉幾度？想想看：走完一圈回到原點，總共轉了一整圈。

下一課會教怎麼不用複製貼上。 今天先用複製的沒關係。

挑戰二（比較難）

畫一個「彩色的樓梯」：往右一段、往上一段、往右一段、往上一段⋯⋯而且每一段都不同顏色。

卡住了？看提示想想每一段要幾塊積木

每一段是兩塊：筆的顏色設為 → 移動。往右和往上的差別在「面朝幾度」（入門課第 8 課學過：上是 0 度、右是 90 度）。

不想用「面朝」的話，也可以用今天學的「定位到 x: y:」——每一段的終點座標自己算，這樣還順便複習了上一課。
