x 和 y：舞台上的地址

想叫角色「去右上角」，現在你只能用滑鼠拖過去。今天要讓程式自己叫它過去。

今天要學會什麼

用兩個數字說出角色站在舞台的哪裡，然後叫它自己走過去。

今天的一塊積木

定位到 x: 0 y: 0

只有一塊，但那兩個數字要花點時間搞懂。這一課的下面有很多可以動手玩的東西，慢慢玩。

0先講一件小事：存檔

存檔你在入門課學過了：檔案 → 儲存到你的電腦。進階課多一條規矩——

⚠️ 每一節課存成新的檔名，不要蓋掉舊的

  • 檔名這樣取：座號_姓名_進階第1課、座號_姓名_進階第2課⋯⋯
  • 為什麼？進階課的程式會愈做愈大，後面學到「自製積木」和「分身」的時候，很容易改一改就整個壞掉。有舊檔可以退回去，就不用重做。

1一個叫不動的問題

入門課你學過「移動 10 點」和「右轉 90 度」。用這兩塊，你可以叫角色往前走、轉個彎。

但如果我說：「叫它直接去舞台的右上角。」

用移動和轉彎做得到嗎？做得到，但你要一直試——走多遠？轉幾度？試到對為止。而且角色從別的地方出發，答案又不一樣了。

問題出在哪：你沒有辦法「說出」右上角是哪裡。

電腦需要一個地址。就像你家的地址是「○○路 12 號」，舞台上的每一個位置，也有自己的號碼。

猜猜看：舞台正中間那個位置，號碼是多少？

先猜，等一下就會知道答案。

2先看一條線就好

舞台有左右、也有上下，兩個方向一起看太多了。我們先只看左右這一條線。

這條線跟你數學課看過的數線一模一樣：0 在正中間，往右數字愈來愈大，往左⋯⋯

往左就變成負的。−60、−120、−180，愈往左愈小。

🤔 為什麼要用負數？直接從 0 數到 480 不好嗎？

  • 可以，但那樣「正中間」會變成 240——一個很難記的數字。
  • 把 0 放中間之後，左右兩邊剛好對稱：右邊最遠是 240，左邊最遠就是 −240。只要記一個數字。
  • 而且「負的」剛好就是「反方向」的意思。看到負號，就想成「往另一邊」，不用想得太複雜。

下面這條線可以點。直接點你覺得對的位置，把小貓放過去：

把小貓放到 0 的位置

點線上任何地方都可以。差一點點沒關係，方向對就算過。

← 負的 正的 →
🐱

點一下上面那條線，開始第一題。

3兩條線合起來，就是舞台

剛剛那條是左右的線，Scratch 叫它 x。

還有一條上下的線，叫 y。規矩一樣：中間是 0，往上愈來愈大，往下變成負的。

把兩條線交叉疊在一起，中間那個交叉點就是 (0, 0)——舞台的正中央。

下面這個舞台可以直接拖小貓。 一邊拖，一邊看左邊和下面那兩條線上的點怎麼跟著跑：

(0, 0) (−240, 180) (240, 180) (−240, −180) (240, −180) 🐱
x 座標0 y 座標0

上面那兩個框，就是 Scratch 舞台上會出現的監看框。等一下你在電腦上勾起來，長得一模一樣。

試試看：把小貓拖到四個角落各停一次

  • 左上角 (−240, 180)
  • 右上角 (240, 180)
  • 左下角 (−240, −180)
  • 右下角 (240, −180)

用滑鼠按住小貓，拖著它在舞台上走走看。

💡 四個角落的數字，其實只有兩個

  • 左右最遠：240（右邊）和 −240（左邊）
  • 上下最遠：180（上面）和 −180（下面）
  • 所以不用背四個角落，只要記住「右邊大、上面大」，再記 240 和 180 就好。
等一下，為什麼往下是負的？我覺得往下應該愈來愈大耶很多人都這樣想，點我

會這樣想很正常，因為你平常看到的東西都是「往下數字愈大」——課本的頁數、電梯的樓層數字往下按⋯⋯

但 Scratch 的 y 是照數學課的數線做的：0 在中間，往上是正的，往下是負的。跟溫度計一樣——零下 5 度寫成 −5，在 0 的下面。

記法：把 y 想成溫度計，豎著放的。 往上爬是正的，掉到 0 以下就變負的。

4四個區域，正負的組合

兩條線把舞台切成四塊。每一塊的正負組合都不一樣：

左上＝x 負、y 正

剩下三塊你自己推推看。下面來點名——看題目，點對應的那一塊：

x 是正 、y 是正 → 點哪一塊？

四題，點點看。

5叫它自己過去

知道地址之後，就可以用這塊積木了。它在藍色的「動作」裡：

定位到 x: 0 y: 0

它不會慢慢走過去，是直接瞬間跳過去。填什麼數字，角色就出現在哪裡。

下面有五個目標。 把數字打進積木裡，按「執行」，看小貓跳得準不準：

讓小貓跳到 綠色虛線圈 的位置

差 20 點以內就算過關。打錯也沒關係，小貓會跳到你打的地方，看得出來差在哪。

(0, 0) ◎ 🐱
定位到 x: y:

第一題的目標已經放好了，看看它在哪一區。

偷看一下：「定位到」用打字的怎麼寫？好奇再點 
from turtle import *      # 準備工作

goto(100, 50)           # 定位到 x: 100 y: 50

goto 是英文的「去到」。括號裡的兩個數字，前面那個是 x，後面那個是 y——跟積木上的順序一模一樣。

連負數的寫法都一樣：goto(-120, -90) 就是積木填 x: −120 y: −90。

6反過來：看位置，說出號碼

剛剛是「給號碼、放角色」。現在反過來——角色已經在那裡了，它的號碼是多少？

這個比較難，但也比較有用：等一下你在 Scratch 裡玩的時候，常常是先把角色拖到滿意的位置，再去看它的號碼是多少，然後把號碼抄進積木裡。

小貓現在站的位置，座標是多少？

先看它在哪一區（正負），就可以刪掉一半的選項。

(0, 0) 🐱

四題。

7最容易搞錯的三件事

⚠️ 一、往下是負的，不是愈來愈大

  • 想往下移動，y 要變小（往負的方向）。
  • 記法：y 是豎著的溫度計，往上爬是正的。

⚠️ 二、x 和 y 填反了

  • x 一定是左右，y 一定是上下，不會換。
  • 記法：x 的兩撇像一把打橫的剪刀，y 有一根往下的尾巴，是直的。

⚠️ 三、以為角色會「走」過去

  • 「定位到」是瞬間跳，中間不會經過。
  • 想看到它走過去的路線，要等下一課的畫筆——下筆之後再定位，就會留下一條線。

8換你在電腦上做

上面玩過的東西，現在到真的 Scratch 裡做一次。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 6
  1. 打開 Scratch，在動作那一區的下面，找到 x 座標 和 y 座標，把前面的方框勾起來
  2. 看舞台左上角——出現兩個監看框了，跟講義上那兩個一樣
  3. 用滑鼠把角色拖來拖去，一邊拖一邊看那兩個數字怎麼變
  4. 把角色拖到四個角落各停一次，把看到的數字記下來
  5. 拖出 定位到 x: y:，填 x: 0 y: 0，點一下積木，角色會跳回正中間
  6. 改成 x: −200 y: −150（記得加小橫槓），再點一次
🎲 試試看 不用照順序，挑喜歡的做 👇 0 / 5
只改 x，y 不動連點幾次，角色會排成一條橫的線。這就是「x 管左右」。
只改 y，x 不動這次排成直的。y 管上下。
兩個都填 0不管角色跑到哪裡，一按就回正中間——這是最好用的「救援積木」。
填超過範圍的數字像 x: 500。角色會卡在邊邊，不會真的跑出去。
把角色拖到你喜歡的位置，再抄號碼看監看框的數字，把它填進積木裡。這招之後每一課都會用到。

★做完了？來挑戰

挑戰一

做一個「瞬間移動」的角色：按 1 跳到左上角、按 2 跳到右上角、按 3 跳到左下角、按 4 跳到右下角。

卡住了？看提示先自己想 3 分鐘

需要四串程式，每一串長得一樣，只有兩個地方不同：按哪個鍵，還有定位到的兩個數字。

帽子積木是入門課第 7 課的 當按鍵被按下，點 ▾ 就可以改成 1、2、3、4。

看參考答案真的想不出來再點
當 1 鍵被按下
定位到 x: -200 y: 150

另外三串一樣，只要換數字：
2 鍵 → x: 200 y: 150　　3 鍵 → x: -200 y: -150　　4 鍵 → x: 200 y: -150

沒有用滿 240 和 180，是因為角色有大小，貼到最邊邊會被切掉一半。留一點空間比較好看。

挑戰二（比較難）

做一個「你猜我在哪」的小遊戲：按綠旗，角色跳到一個位置，你自己先猜座標是多少，再看監看框對不對。

卡住了？看提示想想怎麼讓它每次都不一樣

先做最簡單的版本就好：綠旗 → 定位到你自己決定的一個位置，然後把監看框取消勾選，猜完再勾回來對答案。

想讓它每次都跳到不一樣的地方？那需要「隨機取數」——那是第 6 課的東西，你可以先偷偷去運算區找找看那塊綠色的積木，找到就拿來用。
