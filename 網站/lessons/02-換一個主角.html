換一個主角

小貓可以退休了。今天你會挑一個自己喜歡的角色，還會學會最重要的一件事——存檔。

今天要做出什麼

一張自我介紹卡：你挑的角色，站在你挑的場景裡，說出你的名字。

今天會學會三件事

  1. 換一個角色
  2. 換一個背景
  3. 存檔 —— 沒有它，下禮拜你的作品就不見了

1跟小貓說再見

還記得畫面右下角那一區嗎？那是角色列表——所有演員都排在那裡。小貓就住在那裡。

1積木區指令的倉庫
2程式區拼積木的地方
3舞台表演的地方
🐱
4角色列表今天都在這一區動手

要刪掉小貓，在角色列表裡的小貓上面按滑鼠右鍵，選「刪除」。或者點小貓右上角的垃圾桶。

刪錯了怎麼辦？點我看答案

不用擔心。按鍵盤的 Ctrl + Z 可以救回來（就是「復原」）。

就算救不回來也沒關係——待會你本來就要去角色庫挑新的角色，再挑一次就好。

2挑一個新主角

角色列表的右下角有一個貓咪頭的圓形按鈕，把滑鼠移上去，會跳出「選個角色」。點下去就會打開角色庫。

裡面有幾百個角色，上面還可以按分類找——動物、人物、奇幻、舞蹈、食物……慢慢挑，挑你真的喜歡的。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 3
  1. 把小貓刪掉
  2. 點右下角的圓鈕，打開角色庫
  3. 挑一個你喜歡的角色，讓它站上舞台
可以放很多個角色嗎？點我看答案

可以喔！你想放幾個都行，角色列表會一個一個排下去。

不過今天先放一個就好，把一個角色弄熟。等我們學到第 10 課，會讓兩個角色一起演戲，那時候就有得忙了。

3換一個場景

角色有了，但站在一片白色裡怪怪的。畫面最右下角還有一個按鈕，是背景——點它就能打開背景庫。

背景跟角色有什麼不一樣？點我看答案

角色是演員，會走來走去、會說話。背景是舞台的布景，不會自己動。

所以程式幾乎都是寫在角色身上，不是寫在背景上。

4讓新主角自我介紹

上禮拜的積木，這禮拜一樣能用。

⚠️ 很重要：程式是寫在角色身上的。 剛剛你刪掉小貓的時候，小貓身上的程式也一起不見了。

你在小貓身上寫好程式，然後把小貓刪掉，換成一隻狗。狗會照著做嗎？

先猜猜看，選一個。

那就動手吧。最少要有這兩塊，剩下的你自己加：

⚑ 當綠旗被點擊
說出 我是 ○○○
✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 3
  1. 在新角色身上拖出「當綠旗被點擊」
  2. 接上「說出」，把字改成你自己的名字
  3. 按綠旗，確認說出來的是你的名字

★最重要的一件事：存檔

做得很棒。但是——

如果你現在直接把 Scratch 關掉，下禮拜還看得到你的作品嗎？

先猜猜看再往下看。

怎麼存？

看畫面最上面那排，第一個字是「檔案」。點它 → 選 「儲存到你的電腦」。

檔名要怎麼取？

檔名不是隨便打的。取得好，你自己下禮拜找得到；取不好，一堆檔案長得一樣，你會找到懷疑人生。

✓ 這樣取很好

  • 03_王小明_第2課
  • 03_王小明_自我介紹

一看就知道是誰的、哪一課。

✗ 這樣取會出事

  • 未命名過幾週你會有五個「未命名」
  • aaa兩天後你就忘了這是什麼
  • 我的作品最新版最終版真的最後下一個是什麼？
💾 動手存檔 這四步一定要做完 👇 0 / 4
  1. 點最上面的「檔案」
  2. 選「儲存到你的電腦」
  3. 把檔名改成 座號_姓名_第2課
  4. 按下「存檔」，看到檔案存好了

⚠️ 存檔卡住了？先看這裡

  • 找不到「檔案」在哪 —— 在畫面最上面那排，最左邊，地球圖示的右邊。
  • 不知道要存到哪個資料夾 —— 老師會告訴你存哪裡，記得每次都存在同一個地方。
  • 存完好像沒反應 —— 正常的！存檔成功通常很安靜，畫面不會有大變化。
  • 三個都試過還是不行，再舉手找老師。

6下禮拜怎麼打開

存好了，那要怎麼再打開？一樣點「檔案」，這次選 「從你的電腦挑選」，找到你的檔案，打開就好。

✋ 現在就試一次 不要等下禮拜才發現打不開 👇 0 / 3
  1. 把 Scratch 整個關掉（不要怕，你已經存過了）
  2. 重新打開 Scratch，點「檔案 → 從你的電腦挑選」
  3. 找到你的檔案打開，確認角色、背景、程式都還在

💡 這一步是今天最值得做的練習。現在試過一次，下禮拜你就會很有把握。

7自由玩一玩

下面每一格都用今天學的東西就能做到。挑你有興趣的試，試過就打勾。

🎲 試試看 不用照順序，挑喜歡的做 👇 0 / 6
找一個會動的角色有些角色有很多造型，看看角色庫裡哪些看起來會動。
換三次背景換換看不同場景，哪一個跟你的角色最搭？
讓角色說三句話介紹自己的名字、幾年幾班、最喜歡什麼。
幫角色改個名字角色列表裡可以改角色的名字，取一個你喜歡的。
存第二個檔換個角色重做一次，用不同檔名存起來。
把兩個檔案輪流打開確認兩個都存成功了，而且內容不一樣。

★做完了？來挑戰

挑戰一

做一張完整的自我介紹卡：你挑的角色、你挑的背景，走幾步，說出你的名字和一件你喜歡的事。做完存檔。

看參考答案先自己做做看
⚑ 當綠旗被點擊
說出 大家好
移動 80 點
說出 我是王小明
說出 我最喜歡打籃球

你的角色、背景、台詞都跟這個不一樣才對 —— 這是你的自我介紹卡。

挑戰二（比較難）

做出三張不同的介紹卡，各用不同的角色和背景，分別存成三個檔案，然後一個一個打開來檢查。

卡住了？看提示想想檔名

關鍵在檔名。三個檔案如果都叫一樣的名字，第二個會蓋掉第一個。試試看 _1、_2、_3 這樣分。
