完成，然後演給大家看

這學期的最後一節課。把作品收尾，然後上台讓大家看看你做了什麼。

今天的流程

前半節：把作品做完、除錯、存檔。
後半節：輪流上台發表。

第一件事

打開你上週的檔案：檔案 → 從你的電腦挑選，找到 座號_姓名_期末專題。

1先把基本版做完

回頭看你上週規劃單的第 ④ 格——那三件「一定要做到」的事。

先把它們全部做完，再考慮加新東西。做到一半的功能不如沒有。

🥉 完成基本版 做完一步就打勾 👇 0 / 4
  1. 打開上週的檔案，確認東西都還在
  2. 規劃單第 ④ 格的三件事，全部做完
  3. 從頭到尾完整跑一次，確認沒有卡住的地方
  4. 存檔
🥈 還有時間就加 上週第 ⑤ 格寫的那些 👇 0 / 4
  1. 加上音效，作品會生動很多
  2. 加上背景，或換一個更搭的
  3. 加一句開場說明，讓別人知道怎麼玩／在看什麼
  4. 加一串綠旗歸位：位置、尺寸、造型都設回開始的樣子

2發表前，自己抓一次蟲

上台前一定要從頭跑一次。最常出包的就是這幾件事：

🔍 上台前檢查 每一項都要按按看確認 👇 0 / 6
  1. 按綠旗會從頭開始嗎？ 角色會不會停在上次結束的位置？
  2. 連按兩次綠旗會壞掉嗎？ 很多作品第二次就亂掉。
  3. 角色會不會跑出舞台不見？ 需要的話加「碰到邊緣就反彈」。
  4. 對話會不會重疊或太快？ 調「持續 N 秒」的秒數。
  5. 停不下來的東西有辦法停嗎？ 紅色停止鈕，或加「停止 全部」。
  6. 有沒有沒接好、孤零零的積木？ 沒接到帽子的積木永遠不會執行。

⚠️ 第 2 項特別容易被忽略

  • 發表的時候你一定會按不只一次綠旗——示範完，別人想再看一次。
  • 如果角色沒有歸位，第二次跑就會從奇怪的位置開始，或大小不對。
  • 解法：綠旗那一串的最前面加上「定位到 x:0 y:0」「尺寸設為 100%」「顯示」。
  • 現在就按兩次綠旗試試看。
💾 最後存檔 改完一定要再存一次 👇 0 / 2
  1. 點「檔案 → 儲存到你的電腦」，蓋掉舊的
  2. 確認存好了，準備上台

3準備你的三句話

上台不是只有把作品播出來。先想好這三句話，講起來會順很多：

① 我做的是什麼 一句話講完。「這是一個要閃開三顆球的遊戲。」
② 怎麼玩／要看什麼 「用方向鍵移動，碰到球就結束。」讓大家知道要注意哪裡。
③ 最難做的是哪一段，後來怎麼解決的 這句最重要。「球一開始只會左右飛，後來我把面朝改成 45 度就會斜著飛了。」

💡 為什麼第 ③ 句最重要

  • 因為它證明你真的懂自己的程式——不是照抄來的。
  • 因為別人聽了會學到東西——你踩過的坑，別人不用再踩一次。
  • 因為卡住然後解決，本來就是寫程式最重要的能力。做出來很順反而沒什麼好講的。

4發表時間

輪到你的時候，把你的檔案打開，按綠旗，然後講你的三句話。大概一分鐘就好。

上台的人 先按綠旗讓大家看，再講三句話。緊張是正常的——大家都要上台。
台下的人 認真看。看到你不會做的效果，記下來等一下問他怎麼做的。
給回饋的時候 說具體的：「我喜歡球會斜著飛」比「很棒」有用一百倍。

🎤 如果你的作品沒做完

  • 照樣上台。 做到哪裡就演到哪裡，沒有人會笑你。
  • 講你本來想做什麼、卡在哪裡——這反而是很有價值的分享。
  • 真正的程式設計師也常常做不完。會講清楚自己卡在哪，比假裝做完更厲害。

5這學期你走了多遠

第一節課的時候，你只會讓小貓走三步。

現在你會：讓角色動起來、換造型做動畫、用重複讓電腦幫你做一百次、用鍵盤控制、讓角色互相通知、讓程式自己做判斷——而且你做出了四個作品和一個期末專題。

🎓 最後三件事

  • 你的檔案都留著。 想繼續改、想給家人看，隨時可以打開。
  • Scratch 在家裡也能用。 想繼續玩的話，跟家人說一聲，可以裝在家裡的電腦上。
  • 你學到的不只是 Scratch。 「把大問題拆成小步驟」「卡住了先查再問」「做完要測試」——這些不管以後學什麼都用得到。
想知道接下來還可以學什麼？點我

Scratch 還有很多東西沒教：變數（可以做計分！）、分身（一次生出很多角色）、畫筆（讓角色邊走邊畫圖）、還有更多偵測積木。

還記得那些「偷看 Python」的面板嗎？ 那就是長大以後寫程式的樣子。你已經看過 forward()、for、while、if 了——這些在真正的程式裡是一模一樣的東西。

積木不是玩具版的程式。你這學期學的每一個概念，專業的程式設計師每天都在用。
