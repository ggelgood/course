完成，然後演給大家看

這學期的最後一節課，也是整個 Scratch 課程的最後一節。把作品收尾，然後上台讓大家看看你做了什麼。

今天的流程

前半節：把作品做完、除錯、存檔。
後半節：輪流上台發表。

第一件事

打開你上週的檔案：檔案 → 從你的電腦挑選，找到 座號_姓名_進階期末專題。

1先把基本版做完

回頭看上週草圖學習單的第 ①～④ 格——角色、玩法、計分、結束條件。

先把它們全部做完，再考慮加新東西。做到一半的功能不如沒有——能玩比較重要，砍功能不延長。

🥉 完成基本版 做完一步就打勾 👇 0 / 4
  1. 打開上週的檔案，確認東西都還在
  2. 草圖學習單的核心玩法，全部做完
  3. 從頭到尾完整玩一次，確認會計分、會結束
  4. 存檔
🥈 還有時間就加 上週寫的「有時間再加」👇 0 / 3
  1. 加上音效，碰到、計分的那一刻播放一下
  2. 加一句開場說明，讓別人一看就知道怎麼玩
  3. 加一串綠旗歸位：位置、變數、分身都設回開始的樣子

2發表前，自己抓一次蟲

上台前一定要從頭跑一次。進階課特別容易出包的是這幾件事：

🔍 上台前檢查 每一項都要按按看確認 👇 0 / 6
  1. 連按兩次綠旗會壞掉嗎？ 變數有沒有重新設為初始值？
  2. 玩久一點畫面會不會變頓？ 檢查每一個「建立分身」有沒有配對的「刪除此分身」。
  3. 自製積木改一次，呼叫的地方都跟著變了嗎？ 確認沒有殘留舊版本沒改到的呼叫。
  4. 角色會不會跑出舞台不見？ 需要的話加邊界判斷。
  5. 停不下來的東西有辦法停嗎？ 紅色停止鈕，或加「停止 全部」。
  6. 有沒有沒接好、孤零零的積木？ 沒接到帽子的積木永遠不會執行。

⚠️ 第 2 項是進階課專屬的地雷

  • 分身沒刪乾淨，第一次玩不會發現——要玩久一點、玩兩三次才會卡。
  • 發表的時候你一定會示範不只一次，這個問題會被放大。
  • 解法：檢查每一個「建立自己的分身」，都要能找到對應的「刪除此分身」在哪裡觸發。
💾 最後存檔 改完一定要再存一次 👇 0 / 2
  1. 點「檔案 → 儲存到你的電腦」，蓋掉舊的
  2. 確認存好了，準備上台

3準備你的發表內容

上台不是只有把作品播出來。先想好下面這幾句話，講起來會順很多：

① 我做的是什麼 一句話講完。「這是一個要接住掉下來的東西、生命值歸零就結束的遊戲。」
② 我用了幾個變數，各自記什麼 這是進階課發表的固定要求。「我用了兩個變數：分數記得幾分、生命值記還剩幾條命。」
③ 最難做的是哪一段，後來怎麼解決的 「一開始分身生了不刪，玩到後面畫面會頓，後來加了『飛出畫面就刪除』才順。」

💡 為什麼第 ② 句是固定要求

  • 這是最快檢核學生有沒有真的懂變數的方法——講得出來的就是懂了，講不出來的，通常是照抄範例。
  • 「記什麼」比「叫什麼名字」更重要——如果答得出「生命值記還剩幾條命」，代表你真的知道這個變數在程式裡的作用，不是隨便建一個而已。

4發表時間

輪到你的時候，把你的檔案打開，按綠旗，然後講你準備的內容。大概一分鐘就好。

上台的人 先按綠旗讓大家看，再講三句話，記得講變數那句。緊張是正常的。
台下的人 認真看。看到你不會做的效果，記下來等一下問他怎麼做的。
給回饋的時候 說具體的：「我喜歡分身生成的速度」比「很棒」有用一百倍。

🎤 如果你的作品沒做完

  • 照樣上台。 做到哪裡就演到哪裡，沒有人會笑你。
  • 講你本來想做什麼、卡在哪裡——這反而是很有價值的分享。
  • 真正的程式設計師也常常做不完。會講清楚自己卡在哪，比假裝做完更厲害。

5這學期你走了多遠

開學第一節課，你只會用滑鼠拖角色到 (100, 50)。

現在你會：用座標和畫筆畫出圖形、用變數記分數、用隨機讓每次都不一樣、用「如果⋯否則」做判斷、把一段程式包成自己的積木、還有——讓一份程式同時有很多個自己在跑。你做出了四個作品和一個期末專題。

🎓 最後三件事

  • 你的檔案都留著。 想繼續改、想給家人看，隨時可以打開。
  • 「程式」和「執行中的程式」是兩件事。 這是這學期唯一一個真正的電腦科學觀念——同一份程式碼，可以同時有很多份在跑，各跑各的。想通這件事，以後學任何語言都會受用。
  • 你學到的不只是 Scratch。 「把大問題拆成小步驟」「先讓它撞牆，再學怎麼解決」「改一次、全部都改」——這些以後學任何語言都用得到。
想知道接下來還可以學什麼？點我

Scratch 還有清單（list）沒教——需要同時理解「一個名字裝一整排」和「第幾項」，是變數之後的另一個抽象跳躍，留給下學期。

還記得那些「偷看 Python」的面板嗎？ 定義、呼叫、變數、`for`、`if`⋯⋯這些在真正的程式語言裡是一模一樣的東西，只是不用拖積木、改用打字。

積木不是玩具版的程式。你這學期學的每一個概念，專業的程式設計師每天都在用。
