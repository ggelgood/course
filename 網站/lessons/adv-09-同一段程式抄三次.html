同一段程式，抄三次

今天不教新積木。老實說，今天的目的就是讓你親身感受一個麻煩——下禮拜的積木就是為了解決它。

今天要做出什麼

三個角色都會閃爍，而且老師會在中途臨時改需求兩次。

今天怎麼上

照講義做，老師說改就改——不用想有沒有更快的方法，先把它做完就好。

1打開範例檔

下載這一課最下面的範例檔，打開之後會看到三個角色，程式都還是空的。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 2
  1. 下載並打開 adv-09-三角色閃爍.sb3
  2. 確認角色區有三個角色，點每一個，程式區都是空的

2先幫第一個角色做「閃爍三下」

點選第一個角色，拼出這串：

⚑ 當綠旗被點擊
重複 3 次
隱藏
等待 0.2 秒
顯示
等待 0.2 秒

按綠旗試試看，角色應該會一閃一閃三次。

3把程式複製給另外兩個角色

不用重新搭一次。整段程式可以直接拖到角色縮圖上，就會複製一份過去：

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 2
  1. 把第一個角色的程式，拖到第二個角色的縮圖上
  2. 再拖一次給第三個角色，確認三個角色都會閃爍

三個角色現在都有「閃爍三下」的程式。如果你只改第一個角色的程式（例如改成閃五下），另外兩個角色會跟著變嗎？

想想「複製」的意思。

4老師突然說：「改成閃五下」

📢 新規則：三個角色都要改成「閃五下」

  • 把三個角色的「重複 3 次」都改成「重複 5 次」。
  • 一個角色改一次，三個角色要分別點開、分別改。
✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 3
  1. 第一個角色：重複 3 次 → 重複 5 次
  2. 第二個角色：重複 3 次 → 重複 5 次
  3. 第三個角色：重複 3 次 → 重複 5 次

5老師又說：「不對，改成閃兩下，而且要更快」

📢 新規則：三個角色都要改成「閃兩下，等待時間變成 0.1 秒」

  • 把三個角色的「重複」改成 2 次。
  • 把三個角色、每個角色裡的兩個「等待 0.2 秒」都改成「等待 0.1 秒」。
  • 算算看：這一次總共要改幾個數字？
✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 3
  1. 第一個角色：重複改成 2 次，兩個「等待」都改成 0.1 秒
  2. 第二個角色：重複改成 2 次，兩個「等待」都改成 0.1 秒
  3. 第三個角色：重複改成 2 次，兩個「等待」都改成 0.1 秒

6想一想，不用現在回答

剛才那兩次「臨時改需求」，你總共改了幾個地方？如果老師再宣布一次「改成閃十下」，你要再改幾個？

🤔 留一個問題到下禮拜

  • 有沒有辦法「改一次」，三個角色就一起跟著變？
  • 不用現在想出答案，先把這個不方便的感覺記住就好。
  • 下禮拜的積木，就是為了解決今天這個問題而生的。
