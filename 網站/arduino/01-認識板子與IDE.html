認識板子與 IDE

這學期你會做出好幾個自己設計的裝置，最後還會跟 AI 助手一起共創程式。但今天完全不碰 AI——先把最基本的環境搞懂，之後才不會分不清是哪裡的問題。

今天要做出什麼

讓板子上一顆內建的燈自己閃起來——不改任何程式，只確認「電腦、板子、軟體，三個東西都接得通」。

今天不做的事

今天不寫任何一行程式，也不接任何零件。先把工具用熟，下一課才開始接線。

1你手上的兩塊板子

桌上有兩塊板子疊在一起：

💡 兩塊板子分別是什麼

  • 下面那塊（Arduino UNO）：真正的「大腦」，你寫的程式會存在這裡，靠它運算。
  • 上面那塊（Sensor Shield 擴展板）：把 UNO 的接腳整個複製一份、標好用途，讓你不用直接對著 UNO 密密麻麻的針腳，改成插進標好字的插槽就好。這學期所有零件都插在這塊擴展板上，不會直接碰 UNO。

先不用管擴展板上那些插槽——下一課才會正式教怎麼看。今天只要記得：兩塊板子疊在一起，中間的針腳要對齊插緊，不能歪一邊。

2安裝 Arduino IDE

IDE 是你等一下要用來寫程式、把程式送進板子裡的軟體，全名是「整合開發環境」，不用背這個詞，知道它是「寫程式用的軟體」就好。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 3
  1. 照老師指示的位置下載並安裝 Arduino IDE
  2. 安裝好之後打開它，畫面應該會有一大塊空白區域（等一下要放程式碼）
  3. 用 USB 傳輸線把板子接到電腦

⚠️ USB 傳輸線的一個大坑

有些 USB 線只能充電，不能傳資料（常見於手機的隨附充電線）。如果等一下 IDE 完全找不到板子，先換一條線試試看，這是最常見的原因之一，不是你操作錯。

3認識 IDE 畫面上的東西

打開 IDE，你會看到這幾個區域：

中間一大塊空白 程式碼會寫在這裡。今天先不用管裡面寫了什麼。
→ 上傳按鈕 一個圓圈裡有箭頭的按鈕，按下去程式就會送進板子裡。
下面黑色小視窗 上傳成功或失敗，訊息會出現在這裡。以後排查問題常常要看這裡，先認識它長什麼樣子。
工具／板子、埠 要告訴 IDE「我接的是哪一塊板子、哪一個連接埠」，選錯了程式就送不進去。

4上傳一支現成的程式，什麼都不改

Arduino IDE 內建一支範例程式叫 Blink（閃爍），會讓板子上一顆內建的小燈一直閃。今天的任務只有：打開它、選對板子和埠、按上傳，不改任何一個字。

✋ 動手做 做完一步，就點一下下面的格子打勾 👇 0 / 5
  1. 點選單裡的「檔案」→「範例」→「01.Basics」→「Blink」
  2. 跳出一個新視窗，裡面已經有寫好的程式碼——不用看懂，也不要改
  3. 點「工具」，確認板子選的是 Arduino UNO
  4. 點「工具」→「埠」，選有出現的那個選項（通常只有一個）
  5. 按上傳按鈕（圓圈箭頭），等下面黑色視窗跑完

成功的話，板子上會有一顆小燈（通常標著 L）自己一直閃——不用接任何東西，這顆燈是板子本身內建的。

如果上傳的時候，「工具」→「埠」裡面完全沒有任何選項可以選，最可能的原因是什麼？

想想板子要「被電腦看到」需要什麼。

⚠️ 今天最常見的三個狀況

  • 埠選單是空的 —— 換一條 USB 線試試看，很多線只能充電。
  • 上傳按下去，黑色視窗跳出紅字 —— 先看「板子」和「埠」有沒有選對，這是今天最常見的紅字原因。
  • 板子上很多顆燈亮著，但 L 燈沒有閃 —— 板子有通電是好事（代表有電源），但要看清楚哪一顆才是標 L 的那顆，其他燈本來就會一直亮，不是閃的那顆。
  • 都試過還是不行，舉手找老師，不要一直重複按上傳。
