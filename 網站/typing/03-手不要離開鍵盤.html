手不要離開鍵盤

打字的時候，手常常要離開鍵盤去點滑鼠。今天讓手完全不用離開。

今天要弄懂的三件事

  • 打錯字不用整句刪掉重打
  • 組合鍵要怎麼按住才有用
  • 怎麼截圖、截完圖去哪裡找

能用鍵盤做，就不要動滑鼠

手離開鍵盤再放回去，比你想的花時間。
今天教的每一招，都是為了讓手留在原地。

1打錯了，不要整句刪掉重打

很多人有一個壞習慣：打到第十個字，發現第三個字打錯了， 就一路按 Backspace 刪回去，刪掉七個字， 只為了改一個字，然後再全部重打一次。

游標現在停在一整句話的最後面， 但打錯的字在最前面。你會怎麼做？

提示：想想第 1 課學過的那幾顆鍵，哪一顆能直接跳過去？

用滑鼠點過去當然也做得到，但手要離開鍵盤。 Home 一按，手完全不用動，這就是今天整節課要練的事。

正確的做法，其實全部都是第 1 課學過的鍵， 只是今天要真的把它們用起來：

先「走過去」

方向鍵把游標移到錯字旁邊。

字很長的話，用 Home End 直接跳到頭尾，比一格一格移快得多。

再「刪掉它」

錯字在游標左邊 → 用 Backspace

錯字在游標右邊 → 用 Delete

下面這個游標實驗室你在第 1 課玩過，這次換一句比較長的話。 練習只用「走過去、刪掉它」這兩步，改中間的錯字，不要整句重打。

⚠️ 這句話錯在哪

  • 「我今天再學校吃了午餐」，「再」應該是「在」。 游標停在「再」的後面，先用 Backspace 刪掉「再」， 再打一個「在」，兩下就改完，不用整句重打。

2組合鍵要「按住」

接下來要教的東西，全部都是兩顆鍵一起按。 這句話聽起來很簡單，但很多人第一次用會失敗，原因都一樣。

小美想用 Ctrl 配合 C 這個組合鍵，她的做法是： 先按一下 Ctrl、放開， 再按一下 C、放開。結果沒有用。哪裡錯了？

記住這個動作：Ctrl 按住不放 → 再去按另一顆 → 兩個一起放開。 下一節開始，每一個快捷鍵都要照這個方法按。

3快捷鍵大集合

下面六個是最常用的快捷鍵。手指放在鍵盤上， 照剛剛學的方法（按住不放、一起放開）試試看。 每一格都要你真的按一次，按對了才會知道。

🌟 先學這個：Ctrl + Z 復原

為什麼先教這個？因為它是一張安全網。 知道自己隨時能退回去，才敢放心去試別的快捷鍵，不怕按錯。

任務：按出「復原」

Ctrl ＋ Z

複製、貼上、剪下、全選

這四個是一組，打過的字不用重打，一整篇文章也能一次搬走。

Ctrl + C　複製

把選起來的東西複製一份放進剪貼簿，原本的還在。

Ctrl + X　剪下

跟複製很像，差別是原本的會不見，等於「剪走」。

Ctrl + V　貼上

把剪貼簿裡的東西貼到游標所在的位置。

Ctrl + A　全選

一次選起整篇，通常接著就是 Ctrl + C 整篇複製。

任務：按出「複製」

Ctrl ＋ C

任務：按出「貼上」

Ctrl ＋ V

任務：按出「剪下」

Ctrl ＋ X

任務：按出「全選」

Ctrl ＋ A

Shift：中英文切換

這一顆跟前面幾個不一樣，不用配別的鍵，單獨按一下就好。 是打字時最常按到、卻最少人知道用途的一顆。

任務：只按一下 Shift（不要配別的鍵）

⇧ Shift

4截圖：把螢幕上的東西存下來

截圖對你很實用：交作業、問同學問題、把畫面存下來， 都要靠它。今天教的方法完全不用滑鼠。

主要用這一組：Win + Shift + S

這是三顆鍵一起按：⊞ Win ＋ ⇧ Shift ＋ S。 按下去之後，螢幕會變暗，滑鼠會變成一個十字， 拖曳框出你要的範圍就完成了。

⚠️ 這是全班最容易卡住的地方

  • 「我截了啊，圖呢？」螢幕上真的什麼都不會出現， 因為截好的圖是放進剪貼簿，不是存成一個檔案。
  • 要把圖拿出來看，得先打開一個能貼圖的軟體 （例如小畫家），再按 Ctrl ＋ V 貼上，圖才會出現。

完整流程是這四步，接在一起才算完成，缺一步都不行：

  1. 按 Win + Shift + S，拖曳框出要截的範圍
  2. 打開小畫家（或任何能貼圖的軟體）
  3. 按 Ctrl + V 貼上，圖才會出現
  4. 存檔，才能真的留下來

另外兩種，知道就好

PrtSc

截整個螢幕，一樣要用 Ctrl + V 貼出來才看得到。

Alt + PrtSc

只截目前作用中的視窗，旁邊的東西不會被拍進去。

⚠️ 這幾顆鍵要老師先在教室電腦試過

  • Windows 10 和 11 的截圖行為不完全一樣，Win 11 的 PrtSc 有可能直接開啟一個截圖工具，跟這裡寫的不同， 以老師示範的為準。

5同一組快捷鍵，三個地方各玩一次

今天學的快捷鍵不是只有記事本能用，幾乎每一個軟體都通用。 下面三個地方各玩一次，體會一下這件事。

✋ 動手做 照順序做一遍，做完就打勾 👇 0 / 3
  1. 記事本：打一段字，用 Ctrl + A 全選， Ctrl + C 複製，貼到下面一行，看看是不是變成兩份
  2. 檔案總管：找一個檔案，Ctrl + C 複製、 Ctrl + V 貼上，出現一個「- 複製」的檔案， 代表 Ctrl + C 不是只能複製文字，也能複製檔案
  3. 瀏覽器：在這一頁選一段字，Ctrl + C 複製， 切到記事本按 Ctrl + V 貼上

第三步你應該會發現：同一組快捷鍵，記事本、檔案總管、瀏覽器都能用。 這就是今天真正該記住的事：快捷鍵不是某一個軟體專屬的，是整台電腦通用的。

打開記事本和小畫家，下面每一格都可以真的試一次。 挑你有興趣的做，試過就打勾。

★做完了？來挑戰

挑戰一

在記事本打一句話，然後完全不用滑鼠、也不用 Backspace 或 Delete， 把整句話變成兩份，貼在上下兩行。

卡住了？看提示先自己想 3 分鐘

拆成三件事：先選起整句話， 複製它， 換行之後貼上。

選起一整句最快的方法，今天教過哪一個快捷鍵？

看挑戰一的參考做法真的想不出來再點

1. 按 Ctrl + A 全選這句話

2. 按 Ctrl + C 複製

3. 按 End 跳到最後面，按 Enter 換行

4. 按 Ctrl + V 貼上

挑戰二（比較難）

用 Win + Shift + S 截一張你桌面的圖， 貼到小畫家之後，不用滑鼠，只用今天學過的快捷鍵， 把圖裡的某一小段文字複製到記事本。

卡住了？看提示回想截圖的完整流程

小畫家裡的圖是圖片， 沒辦法選取「文字」。這題真正要練的是整個截圖流程走一遍， 重點放在截圖、貼上、存檔這三個步驟有沒有都做到。

今天你學會了不整句重打、組合鍵怎麼按、還有截圖的完整流程， 手已經可以從頭到尾留在鍵盤上了。

回到第 1 課那個問題：幾萬個中文字，怎麼用這麼少的鍵打出來？ 你已經知道注音是怎麼做到的了。但注音不是唯一的答案。

下一課要看看其他發明家怎麼解這一題。 拼音、倉頡、無蝦米，每一種想法都不一樣， 而且說穿了，全部都只分成兩派。
