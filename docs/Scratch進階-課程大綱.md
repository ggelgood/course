# Scratch 進階 · 十七課大綱

搭配 [`Scratch進階-課程地圖.md`](Scratch進階-課程地圖.md) 使用。
地圖決定**教什麼、為什麼這樣排**；這份大綱決定**每一節課的 28 分鐘怎麼用**。

製作講義時，一課一課照這份大綱寫，不用回頭重新設計流程。

---

## 共同規格

**時間**：每節 40 分鐘，扣掉開機登入與存檔關機，**實際規劃 28 分鐘**。
下面每一課的流程都是以 28 分鐘配的，格式是「起–迄分鐘」。老師巡堂時整體會往後拖，**每一課最後 4 分鐘是可以犧牲的**（都放變化練習，不放新東西）。

**每節課的固定結構**（跟入門課一致）：

| 段落 | 分鐘 | 做什麼 |
|---|---|---|
| 開場 | 0–5 | 老師投影，提出**這節課要解決的問題**（不是先講積木） |
| 主線 | 5–20 | 學生照講義做出最小可動版本 |
| 變化 | 20–28 | 同一組積木換三種玩法，學生自己選 |

**存檔檔名**：`座號_姓名_進階第N課`。
**進階課刻意不覆蓋舊檔**——自製積木和分身很容易改到壞掉，要留得住退路。這件事在第 1 課講一次，第 10 課再提醒一次。

**素材檔名**：`adv-NN-序號-短名.png` / `.gif`，放 `網站/media/`。
加 `adv-` 前綴，**避免和入門課的 `01`–`17` 撞名**。範例檔放 `網站/files/`，命名 `adv-NN-短名.sb3`。

**Python 面板**：只在該積木**第一次出現**的那一課附，預設收合，沒有對應寫法就不附。每課大綱最後一行會註明這課要附哪些。

# 單元一 位置說得準（第 1–3 課）

## 第 1 課 x 和 y：舞台上的地址

**這節課要解決的問題**：想叫角色「去右上角」，只能用滑鼠拖——程式沒辦法叫它自己過去。
**重量**：**重**（座標系，本學期第一個重概念）
**新積木**：`定位到 x: y:`、`x 座標` / `y 座標`（監看框）

> **⚠️ 這一課的負擔比表面上重，處理方式跟其他課不一樣。**
> 座標系本身不難，難的是**負數在螢幕上看不見**——尤其「往下是負的」跟學生的日常經驗相反（課本頁數、樓層都是往下愈大）。
> 28 分鐘要靠老師講清楚 ±240 / ±180，會變成純照抄。
> **所以這一課的講義做了五個互動練習，把講述改成動手玩**，老師只負責開場和巡堂。
> 講義：[`網站/lessons/adv-01-x和y舞台上的地址.html`](../網站/lessons/adv-01-x和y舞台上的地址.html)

**設計主軸：先一維，再二維。**
直接教 (x, y) 等於同時處理兩個負數。講義刻意先只給**一條數線**練到熟，才把兩條交叉起來變成舞台。

| 分鐘 | 內容 | 對應互動 |
|---|---|---|
| 0–3 | **存檔規矩重申**：進階課每節存新檔，不覆蓋（只講，不示範） | 講義第 0 節 |
| 3–6 | 提出問題：叫角色「去右上角」用移動＋轉彎做得多痛苦。**先猜：正中間是幾號？** | 「猜猜看」選擇題 |
| 6–12 | **只看左右一條線**。0 在中間，右邊正的、左邊負的。學生點數線放小貓，五題 | **A 一條數線** |
| 12–20 | 兩條線疊起來＝舞台。**拖小貓，看它的位置投影到左邊和下面兩條線上**，順便把四個角落各走一次 | **B 舞台主控台** |
| 20–24 | `定位到 x: y:`：打數字讓小貓跳到目標圈，五關 | **D 座標傳送** |
| 24–28 | 到真的 Scratch 裡做一次：勾監看框、拖角色、用積木跳回中心 | 講義第 8 節動手做 |

**課堂上做不完的部分，留給學生自己玩**：象限點名（C）和反向讀座標（E）不排進正課時間，
它們是給快的學生的加碼，也是**下一節課前的複習入口**——第 2 課開場請學生先回來把這兩個做完。

**五個互動練習在做什麼**（都在講義裡，不需要另外準備）：

| | 名稱 | 針對的困難 | 設計重點 |
|---|---|---|---|
| A | 一條數線 | 負數的方向感 | **答完才顯示正確位置**，先畫出來就等於送答案。點錯方向會直接說「方向反了，負數在 0 的左邊」 |
| B | 舞台主控台 | **負數看不見** | 拖小貓時，位置同時**投影到左邊（y）和下面（x）兩條數線**，並拉出兩條虛線。負號變成看得到的東西 |
| C | 象限點名 | 正負的四種組合 | 給「x 負、y 正」，點對應的那一塊。答錯不跳題，先講清楚是左右錯還是上下錯 |
| D | 座標傳送 | 把理解變成打字 | **打錯時小貓真的跳到打錯的地方**，錯在哪一眼看得到；回饋會分別指出是 x 還是 y 的正負反了 |
| E | 反向讀座標 | 從位置說出號碼 | 三個錯的選項分別是**①y 正負反了 ②x 和 y 對調 ③兩個都反**——都是真的會犯的錯 |

**兩個記法（講義裡有，老師巡堂時重複這兩句就好）**：
- **y 是豎著放的溫度計**——往上爬是正的，掉到 0 以下變負的
- **四個角落只有兩個數字**：240 和 180，差別只在有沒有負號。記「**右邊大、上面大**」就好

**常見卡關**：
- **往下是負的**——學生會以為往下 y 也變大。互動 B 的投影線就是為了這個，一定要讓他們拖夠久，不能用講的
- **x 和 y 填反**——互動 E 的第二個選項專門抓這個
- 記不住 240 / 180 → 邊界數字讓他們自己拖出來，不要用背的

**素材**：`adv-01-1-舞台座標圖.png` ★（截圖加標註四角數字）、`adv-01-2-勾選監看框.gif` ★、`adv-01-3-拖角色看數字變.gif` ★
**範例檔**：`adv-01-座標練習.sb3`（四個角落放好標記的舞台，讓 24–28 分鐘那段不用從零開始）
**Python 面板**：`定位到 x y` → `goto(100, 50)`（**第一次出現**）

> **如果 28 分鐘還是不夠**（很有可能）：不要延長，也不要砍互動。
> 座標在**第 2 課還會再碰一次**——畫筆會把每一次移動變成看得見的軌跡，那就是座標的第二次曝光。
> 第 2 課開場的 4 分鐘請保留給「把上週的 C 和 E 做完」，比在第 1 課硬塞有效。

## 第 2 課 畫筆：讓角色邊走邊畫

**這節課要解決的問題**：上一課角色瞬移過去，**中間發生什麼看不見**。
**重量**：輕 ×4（都是「改筆的某個屬性」，同一種思考方式）
**新積木**：加入畫筆擴充（操作）、`下筆`、`停筆`、`全部擦掉`、`筆的顏色設為`、`筆的粗細設為`

| 分鐘 | 內容 |
|---|---|
| 0–4 | **加入擴充功能**：左下角那顆按鈕 → 畫筆。純操作，用 GIF |
| 4–11 | `下筆` 之後再移動，線就出來了。把第 1 課的「走四個角落」重跑一次——**這次看得到路徑** |
| 11–16 | `停筆`（移動不留線）、`全部擦掉`（清乾淨重來） |
| 16–21 | `筆的顏色`、`筆的粗細` |
| 21–28 | 變化：①用滑鼠拖著角色簽自己的名字 ②每畫一段換一個顏色 ③粗細從 1 調到 20 看差別 |

**常見卡關**：
- **忘了「全部擦掉」**，上次的線還在，畫面愈來愈亂 → 養成「綠旗第一塊就是全部擦掉」的習慣，第 3、12 課都要用
- 下筆之後**拖角色也會畫線**，學生以為壞掉了

**素材**：`adv-02-1-加入畫筆擴充.gif` ★、`adv-02-2-下筆前後對比.png`、`adv-02-3-簽名成品.png`
**範例檔**：不需要
**Python 面板**：`下筆/停筆` → `pendown()` / `penup()`；`全部擦掉` → `clear()`；`筆的顏色` → `pencolor("red")`；`筆的粗細` → `pensize(3)`（全部第一次出現）

## 第 3 課 ★ 作品：用重複畫出圖形

**這節課要解決的問題**：畫一個正方形，要重複貼四次一樣的積木。
**重量**：不教新的（重複、轉彎是入門課的東西）
**新積木**：無

| 分鐘 | 內容 |
|---|---|
| 0–6 | 手動畫正方形：`移動 100` + `右轉 90`，複製貼上四組。**先讓他們笨笨地做一次** |
| 6–12 | 改成 `重複 4 次`，結果一樣但短很多 |
| 12–20 | **改成三角形**。學生多半會填 `重複 3 次` + `右轉 60`（用內角）→ 畫出來是歪的 → 一起找出應該是 **360 ÷ 邊數 = 120** |
| 20–28 | 挑戰：正六邊形（60）、正八邊形（45）、`重複 36 次` + `右轉 10` ≈ 圓 |

**常見卡關**：
- **轉的角度用成內角**——這是本課的教學重點，不是意外，要讓它發生
- 忘了 `下筆` 或忘了 `全部擦掉`

**素材**：`adv-03-1-四種圖形成品.png` ★（正方形／三角形／六邊形／圓並排）
**範例檔**：不需要
**Python 面板**：無新積木，不附

# 單元二 記住一個數字（第 4–8 課）

## 第 4 課 變數：給電腦一本記事本

**這節課要解決的問題**：想做一個「按一下加一分」的東西，但**現有的積木全都不會記東西**。
**重量**：**重**（變數）
**新積木**：`建立一個變數`、`將 變數 設為 N`、變數監看框（勾選顯示）

| 分鐘 | 內容 |
|---|---|
| 0–5 | 提出問題：分數要放哪裡？翻遍積木區找不到能存數字的地方 |
| 5–12 | 建立變數 `分數`。**命名是本課重點**：不要用「變數1」，要用看得懂的名字 |
| 12–18 | `綠旗 → 分數設為 0`、`角色被點擊 → 分數設為 100`。舞台上的數字真的變了 |
| 18–24 | 勾選／取消勾選看舞台上出不出現；拖動監看框換位置；再建一個 `生命值` |
| 24–28 | **刻意撞牆**：想辦法讓它「每點一下加一分」。用 `設為` 做不到——每次都跳到同一個數字。**問題留到下週，不給答案** |

**常見卡關**：
- 取名叫「變數1」→ 三週後自己看不懂。**這一課要嚴格要求命名**
- 建好變數但沒勾選，以為沒成功

**素材**：`adv-04-1-建立變數流程.gif` ★、`adv-04-2-舞台監看框.png`
**範例檔**：不需要
**Python 面板**：`建立變數 + 設為` → `score = 0`（**進階課最有價值的一個面板**，值得多寫兩句）

---

## 第 5 課 「設為」和「改變」差在哪

**這節課要解決的問題**：上週的分數加不起來。
**重量**：輕（沿用變數的思考方式），但含**整學期最大的 bug 來源**
**新積木**：`將 變數 改變 N`、`隱藏變數`

| 分鐘 | 內容 |
|---|---|
| 0–6 | 給出 `改變 1`，「按一下加一分」立刻成功 |
| 6–14 | **兩個版本並排做**：`重複 10 次 → 設為 1` vs `重複 10 次 → 改變 1`。一個永遠是 1，一個變成 10。**用一句話收**：設為＝清空重填，改變＝在原本的基礎上加 |
| 14–21 | 應用一：**生命值**（綠旗設為 3、碰到就改變 -1） |
| 21–28 | 應用二：**倒數計時**（設為 10、重複 10 次：改變 -1、等 1 秒） |

**常見卡關**：
- **忘了在綠旗時「設為 0」**，重玩一次分數從上次接續 → 這個錯要抓出來，第 8 課的作品會直接踩到
- 把 `設為` 放進重複裡（本課核心錯誤，已設計成刻意撞牆）

**素材**：`adv-05-1-設為vs改變對比.gif` ★（兩份程式並排跑）
**範例檔**：不需要
**Python 面板**：`改變 N` → `score = score + 1`（順便解釋為什麼 score 要寫兩次）

---

## 第 6 課 隨機數：每次玩都不一樣

**這節課要解決的問題**：做出來的東西**玩第二次就膩了**，因為每次都一模一樣。
**重量**：輕 ×2
**新積木**：`隨機取數 1 到 10`、`+ − × ÷` 運算積木

| 分鐘 | 內容 |
|---|---|
| 0–5 | 提出問題：東西每次都出現在同一個地方 |
| 5–13 | `隨機取數` 塞進 `定位到 x y`（x 用 -240 到 240、y 用 -180 到 180）→ 角色亂跳。**第 1 課的座標範圍在這裡用上了** |
| 13–19 | 隨機也可以塞進尺寸、顏色特效、等待秒數 |
| 19–28 | 變化：①猜數字（電腦想一個 1–10，說出來對照）②會隨機換位置的星星 ③用 `分數 × 10` 做加權計分 |

**常見卡關**：
- **範圍寫反**（`隨機取數 10 到 1`）
- 把隨機積木整塊拖走，忘了它要「塞進另一塊的洞裡」

**素材**：`adv-06-1-隨機塞進定位.gif` ★
**範例檔**：不需要
**Python 面板**：`隨機取數` → `random.randint(1, 10)`（面板裡要一併寫出 `import random`）

## 第 7 課 如果…否則，還有大於小於

**這節課要解決的問題**：入門課學過「如果…那麼」，但**條件不成立的時候什麼都不會發生**。
**重量**：**重**（雙向判斷）
**新積木**：`如果…否則`、`>` `<` `=`

| 分鐘 | 內容 |
|---|---|
| 0–6 | 對比兩塊積木的形狀：`如果…那麼` 只有一個口袋，`如果…否則` 有兩個 |
| 6–14 | `如果 分數 > 10 → 說「過關」，否則 → 說「再加油」`。改分數的值試兩次 |
| 14–20 | `如果 生命值 = 0 → 停止全部`。**這是第 8 課作品的結束條件** |
| 20–28 | 變化：①三種等第（把第二個 `如果…否則` 放進「否則」裡）②碰到不同角色給不同反應 |

**常見卡關**：
- 比較積木的**左右兩格填反**
- 巢狀放太深，自己看不懂 → **超過兩層就叫停**

**素材**：`adv-07-1-兩種如果的形狀.png` ★、`adv-07-2-巢狀等第.png`
**範例檔**：不需要
**Python 面板**：`如果…否則` → `if ... / else`（順便看到縮排）；`>` `<` `=` → `>` `<` `==`（**一定要講 `==` 和 `=` 不一樣**）

## 第 8 課 ★ 作品：接東西計分遊戲

**重量**：不教新的
**新積木**：無

> ⚠️ **這節時間最緊，一定要給半成品範例檔**，不要讓學生從零搭。

| 分鐘 | 內容 |
|---|---|
| 0–4 | 老師投影成品，玩一次給他們看 |
| 4–8 | 打開範例檔（兩個角色、背景已備好，程式是空的） |
| 8–15 | 蘋果：`綠旗 → 重複無限次 → y 改變 -5`；`如果 y < -170 → 定位到 (隨機 x, 180)` |
| 15–21 | 碗：方向鍵左右移動；`如果 碰到 蘋果 → 分數改變 1`，蘋果回到頂端 |
| 21–28 | 自己加規則：漏接扣生命值、限時 30 秒、蘋果愈掉愈快 |

**常見卡關**：
- **綠旗忘了把分數設為 0**（第 5 課埋的地雷在這裡引爆，是好事）
- 碰到判斷放在無限重複外面，只判斷一次

**素材**：`adv-08-1-成品試玩.gif` ★★
**範例檔**：`adv-08-接東西-半成品.sb3` ★★
**Python 面板**：無新積木，不附

# 單元三 包起來（第 9–12 課）

## 第 9 課 同一段程式抄三次

**這節課要解決的問題**：本課的任務是**製造這個問題**，不是解決它。
**重量**：不教新的
**新積木**：無

> **老師紀律：整節課不准劇透。**
> 不要說「下週有更好的方法」，也不要說「這樣很麻煩對不對」。
> 讓挫折自己發生，學生下週才會覺得自製積木是救星。
> （同入門課第 10 課的作法。）

| 分鐘 | 內容 |
|---|---|
| 0–4 | 打開範例檔：三個角色已放好，程式空的 |
| 4–12 | 幫第一個角色做「閃爍三下」（`重複 3 次：隱藏、等 0.2 秒、顯示、等 0.2 秒`），把程式**拖到角色縮圖上複製**給另外兩個 |
| 12–18 | 老師宣布：**「改成閃五下。」** 學生要改三個地方 |
| 18–24 | 老師再宣布：**「不對，改成閃兩下，而且要更快。」** 再改三個地方，六個數字 |
| 24–28 | 收尾提問：**「有沒有辦法改一次，三個都跟著變？」** 讓他們想，不給答案 |

**變化練習**：無——本課的「變化」就是那三輪改需求
**常見卡關**：不知道程式可以拖到角色縮圖上複製 → 這個操作要 GIF

**素材**：`adv-09-1-拖到角色縮圖複製程式.gif` ★
**範例檔**：`adv-09-三角色閃爍.sb3` ★★（**沒有這個檔就撞不到牆**，光搭程式就會用掉整節課）
**Python 面板**：無新積木，不附

## 第 10 課 自製積木：做一塊自己的積木

**這節課要解決的問題**：上週改三次，改到手軟。
**重量**：**重**（把一段程式取名字）
**新積木**：`建立一個積木`（定義帽子）、呼叫自己的積木

| 分鐘 | 內容 |
|---|---|
| 0–4 | 回顧上週的痛，直接宣布今天要解決它 |
| 4–13 | 建立積木「閃爍」，把那段程式搬到 `定義 閃爍` 底下 |
| 13–19 | 三個角色都改成呼叫「閃爍」。**當場改一次定義，三個角色同時變** ← 本課的高潮，一定要留時間讓他們親眼看到 |
| 19–28 | 命名練習：把「跳起來」「變大再變小」也各包成一塊積木。**名字要讓人一看就知道它會做什麼** |

**常見卡關**：
- **把「當綠旗被點擊」接到定義帽子底下** → 定義區不放事件積木
- 建好定義但沒有在主程式呼叫，跑起來什麼都沒發生
- 積木名稱取「積木1」（跟第 4 課的變數命名同一個病）

**素材**：`adv-10-1-建立積木流程.gif` ★、`adv-10-2-改一次三個都變.gif` ★★
**範例檔**：沿用 `adv-09-三角色閃爍.sb3`
**Python 面板**：`定義／呼叫` → `def 閃爍(): / 閃爍()`（**整個進階課最重要的一塊橋**）
**提醒**：本課再提醒一次「存新檔，不要覆蓋」——自製積木改壞了很難救。

## 第 11 課 讓自己的積木帶數字

**這節課要解決的問題**：要閃三下和閃五下，難道做兩塊積木？
**重量**：**重**（參數）
**新積木**：積木的「數字輸入」欄位（參數）

| 分鐘 | 內容 |
|---|---|
| 0–5 | 提出問題：閃 3 下、閃 5 下、閃 10 下，三塊積木？ |
| 5–14 | 編輯「閃爍」積木 → 加入**數字輸入**，命名為 `幾下` |
| 14–20 | **把參數從定義帽子上「拖」進重複次數的洞裡**（不是手打數字）。本課最容易卡的操作 |
| 20–28 | 變化：`正N邊形(邊數, 邊長)` ——兩個參數，接回第 3 課的圖形 |

**檢核學生有沒有真懂**：**問他「這個洞要取什麼名字」**。
取得出「幾下」「幾邊」的就是懂了；答不出來或說「數字」的，是照抄。

**常見卡關**：
- **手打數字而不是拖參數進去** → 看起來會動，但換數字沒反應。本課最大的坑
- 編輯積木時不小心刪掉原本的定義內容

**素材**：`adv-11-1-加入數字輸入.gif` ★、`adv-11-2-拖參數進洞裡.gif` ★★
**範例檔**：不需要
**Python 面板**：帶參數的自製積木 → `def 閃爍(次數):`（點出參數名字在兩邊是同一件事）

## 第 12 課 ★ 作品：用自製積木畫一幅圖

**重量**：不教新的
**這節是第一到第三單元的合流點**——同時用到座標、畫筆、重複、參數。

| 分鐘 | 內容 |
|---|---|
| 0–5 | 回顧第 3 課的圖形，指出當時每換一種圖形就要改兩個數字 |
| 5–15 | 做出 `正N邊形(邊數, 邊長)` 積木（含 `全部擦掉`、`下筆`） |
| 15–22 | 用 `定位到 x y` 換位置，重複呼叫，畫出大小不一的一排圖形 |
| 22–28 | 加顏色、疊起來，組成一幅自己的畫，存檔 |

**變化練習**：同心圖形、彩虹色、隨機位置隨機邊數（把第 6 課的隨機接回來）
**常見卡關**：
- 換位置時**忘了 `停筆`**，圖形之間被連線接起來
- 畫完沒 `全部擦掉` 就重跑，愈疊愈亂

**素材**：`adv-12-1-成品畫作.png` ★
**範例檔**：不需要
**Python 面板**：無新積木，不附

# 單元四 很多個自己（第 13–15 課）

## 第 13 課 一個角色，很多個自己

**這節課要解決的問題**：要下 20 滴雨，難道放 20 個角色？
**重量**：**重**（分身，本學期終點）
**新積木**：`建立自己的分身`、`當分身產生`

| 分鐘 | 內容 |
|---|---|
| 0–6 | 提出問題，並給類比：**一張食譜（程式），照著做出二十盤菜（分身）。食譜只有一份，但二十盤菜各自在各自的桌上** |
| 6–12 | 本尊：`綠旗 → 隱藏 → 重複 20 次：建立自己的分身、等 0.2 秒`。**本尊要藏起來，這個習慣第一節就建立** |
| 12–21 | 分身：`當分身產生 → 顯示 → 定位到 (隨機 x, 180) → 重複無限次：y 改變 -5` |
| 21–28 | 變化：①星星往上飄 ②氣泡邊飄邊變大 ③按空白鍵才生一個 |

**常見卡關**：
- **忘了讓本尊隱藏** → 畫面多一隻不動的東西，學生很困惑
- **把分身的程式接在「當綠旗」而不是「當分身產生」** → 只有本尊會動。本課第一大錯
- 本尊和分身的程式混在同一串

**素材**：`adv-13-1-下雨成品.gif` ★★、`adv-13-2-本尊隱藏前後對比.png` ★
**範例檔**：不需要
**Python 面板**：**不附**——turtle 沒有對應寫法；Python 要做這件事得用類別或串列，硬塞違反「寧可少，不要空」

## 第 14 課 分身要會消失

**這節課要解決的問題**：讓學生**親眼看到分身爆掉**。
**重量**：輕，但**是整學期最不可省略的一課**
**新積木**：`刪除此分身`

| 分鐘 | 內容 |
|---|---|
| 0–8 | **刻意爆掉**：把第 13 課的雨改成 `重複無限次：建立自己的分身`，跑 30 秒。畫面卡住、變慢、行為變得莫名其妙 |
| 8–15 | 加上 `如果 y < -170 → 刪除此分身`，再跑一次，順了 |
| 15–20 | 講清楚：**Scratch 分身上限 300**。只生不刪一定會撞到，而且**撞到的時候看不到任何錯誤訊息** |
| 20–28 | 變化：①碰到角色就刪除（吃掉的效果）②飛出邊界就刪除 ③按一下清空全部分身 |

**常見卡關**：
- **`刪除此分身` 放在本尊的程式裡**（接在 `建立自己的分身` 後面）→ 分身一生出來就沒了
- 刪除放在無限重複外面，永遠執行不到

**加碼（給快的學生）**：建立變數時選「**僅適用於當前分身**」，可以讓每個分身有自己的速度。
**不列入正課**——它牽涉「同一個名字、不同的盒子」，對高年級偏重。

**素材**：`adv-14-1-分身爆掉.gif` ★★（卡住的畫面本身就是教材）
**範例檔**：沿用第 13 課的檔案
**Python 面板**：不附

## 第 15 課 ★ 作品：躲避／射擊小遊戲

**重量**：不教新的
**這節排同儕試玩**（地圖「還沒決定的事」第 2 點的建議位置）。

| 分鐘 | 內容 |
|---|---|
| 0–4 | 老師投影成品，玩一次 |
| 4–8 | 打開半成品（主角、計分、生命值已完成，**缺的就是分身那一段**） |
| 8–18 | 補上分身：射擊版＝按空白鍵生子彈；躲避版＝敵人從隨機位置生出來。**兩版二選一** |
| 18–24 | **同儕試玩**：跟旁邊的人交換玩對方的遊戲，回報一件「怪怪的地方」 |
| 24–28 | 依回饋修一個地方，存檔 |

**變化練習**：難度隨分數上升、加音效、加開始畫面
**常見卡關**：
- 子彈忘了刪除分身（第 14 課的重點在這裡驗收）
- 碰到判斷寫在本尊身上而不是分身身上

**素材**：`adv-15-1-射擊成品.gif` ★★、`adv-15-2-躲避成品.gif` ★
**範例檔**：`adv-15-射擊-半成品.sb3` ★★、`adv-15-躲避-半成品.sb3` ★★
**Python 面板**：無新積木，不附
